# Wakawaka demo

A playable browser prototype with Rings and Building sandboxes, plus a read-only Objects Gallery.

[Play](https://roccella.github.io/wakawaka-demo/) · [Objects Gallery](https://roccella.github.io/wakawaka-demo/model-viewer.html)

Use the Runtime menu to switch sandboxes or open the gallery. On-screen hints show the game controls.

This repository contains generated application files and runtime assets only. The source project and its history are maintained separately.

## Hosting

In Settings → Pages, choose **Deploy from a branch**, **main**, and **/ (root)**.
